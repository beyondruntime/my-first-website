# Code of Conduct

## Our pledge

We want **My First Website** to be a welcoming, respectful, and beginner-friendly open-source community. Everyone participating in project discussions, issues, pull requests, and other community spaces is expected to treat others with courtesy, regardless of experience, background, or identity.

## Expected behaviour

- Be kind, respectful, and constructive.
- Welcome questions and contributions from beginners.
- Give feedback about code and ideas without making personal attacks.
- Respect differences in perspective and experience.
- Take responsibility for mistakes and work to resolve disagreements calmly.

## Unacceptable behaviour

The following behaviour is not tolerated:

- Harassment, bullying, discrimination, or hateful language.
- Personal insults, threats, or deliberate intimidation.
- Unwanted sexual attention or inappropriate content.
- Posting another person's private information without permission.
- Repeated disruption of project discussions or reviews.

## Reporting concerns

If you encounter inappropriate behaviour, contact the repository maintainer privately through a contact method published on their GitHub profile, if available. Do not include sensitive personal information in public issues. If no private contact method is available, use GitHub's reporting and blocking tools.

Please provide relevant links and a description of the incident so it can be reviewed fairly.

## Enforcement

Maintainers may remove inappropriate content, ask contributors to change their behaviour, temporarily restrict participation, or ban repeat or serious offenders. Decisions will take into account the context, severity, and impact of the behaviour.

## Scope

This Code of Conduct applies to repository issues, pull requests, discussions, reviews, and other spaces where people represent or participate in the project.

Thank you for helping build a positive community.
